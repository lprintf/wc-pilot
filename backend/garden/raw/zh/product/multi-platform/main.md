# 多平台统一接入

## 一键接入的渠道

本系统通过企业微信和微信客服 API 提供统一的 AI 客服入口，支持：

- 企业微信：客户群、单聊、微信客服，B2B 私域运营主阵地。
- 微信公众号：菜单嵌入客服入口，关注即能咨询。
- 微信小程序：交易场景内嵌客服组件。
- 视频号 / 搜一搜：官方客服入口。

微信生态外也可扩展至抖音企业号、官网、APP 等渠道。

## 统一管理

所有渠道的对话汇聚到同一个 AI 引擎，统一的：
- 知识库
- 对话策略
- 线索筛选规则
- 数据看板

不需要为每个渠道单独维护一套知识库或客服规则。

## 与个人微信的对比

个人微信号被封后客户和聊天记录全部丢失。企业微信 + 微信客服渠道有：
- 官方 API 支持，不违规。
- 客户资产归属企业，员工离职可继承。
- 会话存档合规。
