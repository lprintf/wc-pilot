# 知识库维护与更新

## 不同于传统方案

大多数 AI 客服的知识库依赖向量数据库或托管平台，更新内容需要：
- 重新向量化索引（耗时且结果不稳定）
- 或登录第三方后台编辑器（有学习成本，数据不在自己手里）

## 本系统的数字花园方案

知识库就是 Markdown 文件夹。每个页面一个 `main.md`，加上 `tags.txt` 标签文件。
- 编辑：用任何文本编辑器或 Obsidian 直接修改 Markdown 文件。
- 索引：编译器启动时扫描所有 .md 文件，秒级重建标签倒排索引。
- 版本：所有 Markdown 文件纳入 Git，有完整修改历史和回滚能力。
- 双向链接：用 `[[页面名]]` 或 `[[页面名|别名]]` 维护文章间关联，自动生成知识图谱。

## 维护成本

- 新增一篇文章：创建一个目录，放入 main.md 和 tags.txt，重启索引。
- 修改内容：编辑 main.md 或 tags.txt，重启索引。
- 不需要导入导出、不需要重新训练、不需要等向量化排队。
