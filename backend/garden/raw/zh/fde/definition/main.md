# FDE 定义

FDE（Forward Deployed Engineer）是嵌入客户真实环境、用工程手段把软件或 AI 能力接入业务流程、交付到生产，并对上线后效果负责的人。

它不同于单纯做 Demo 的售前，也不同于把需求抛回研发的实施顾问。核心差异在于：
- 谁写生产代码
- 谁进入客户环境
- 谁承担上线结果
- 谁把现场经验带回产品

FDE 处理的是模型之外的现实约束：数据质量和流向、权限与安全、遗留系统接口、流程规则、人工兜底、评测和组织采用。

工作通常包含四个连续阶段：发现真正的问题 → 收敛成可验证目标 → 完成系统集成和生产部署 → 根据上线指标持续迭代。共性经验需脱敏沉淀为模板、连接器和评测集，降低下一次同类交付成本。
