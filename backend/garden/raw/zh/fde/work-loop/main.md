# FDE 工作闭环

FDE 交付的不是一个模型，而是一条能被组织接手的工作链。

## 发现—构建—运行—学习

- 发现：在客户流程中找到真正的问题，并收敛成可验证任务。
- 构建：完成系统集成、部署配置、评测和操作手册。
- 运行：根据质量、成本、时延、错误和采用率持续迭代。
- 学习：把共性约束脱敏沉淀为模板、连接器和评测集。

## 验收标准

一个项目只有具备明确 owner、运行手册、告警、预算和数据更新机制，才具备扩张条件。否则不扩张。
