# 成本估算模型
tags: 定价, 成本, 方案

## 成本构成

### LLM 成本

- 成本 = 输入 token 数 x 输入单价 + 输出 token 数 x 输出单价。
- 展示型客服平均每轮约 500-1500 输入 token，200-500 输出 token。
- 实际成本取决于模型版本、提示词复杂度、知识库片段长度和重排策略。
- 可通过缓存历史消息、压缩知识片段和控制输出长度降低 20-50%。

### 开发集成成本

- 已有微信客服 API 通道时，接入成本较低。
- 需评估企微客服、其他渠道 SDK、知识库整理、业务系统对接和前端后台定制。
- 通常分为 PoC、试点、生产化三个阶段。

### 运维成本

- 包括服务托管、监控告警、日志留存、模型配额和安全合规。
- 客户数据敏感度越高，安全审计和数据脱敏成本越高。

## 量级分档（Demo 估算）

| 日均对话量 | 建议方案 | LLM 月成本区间 | 开发集成周期 |
| --- | --- | --- | --- |
| 100-500 | 单客服 PoC | 数百元/月 | 1-3 周 |
| 500-2000 | 试点生产 | 数千元/月 | 2-6 周 |
| 2000-10000 | 多客服生产 | 数万元/月 | 1-3 个月 |
| 10000+ | 定制化集群 | 按量评估 | 2-6 个月 |

以上为 Demo 估算，不代表正式报价。

## 影响因素

- 是否使用向量检索和 embedding。
- 是否需要 CRM、工单系统、消息审计对接。
- 是否涉及医疗、金融等强合规行业。
- 是否需要多语言、多租户、多坐席和复杂 RBAC。
- 是否要求私有化部署或专属模型。

## 优化建议

- 优先做高频问答的知识库，先覆盖 20% 高频问题。
- 先接 1 个渠道，跑通后再复制到其他渠道。
- 用量化和监控指标驱动提示词和知识库迭代。
