AI + 人工

数据边界

后台按内部用户 ID 校验访问范围，不向前端暴露外部身份标识。

清晰、可演进的架构

浏览器通过 Nginx 访问静态前端和 FastAPI API；消息、身份、状态与审计记录保存在后端。当前 Demo 聚焦微信客服消息，不宣称覆盖完整会话内容存档。

微信客服 → FastAPI → SQLite → AI / 人工客服
